How to export stems from your DAW
  • Logic Pro: File → Export → All Tracks as Audio Files. Start at bar 1.
  • FL Studio: File → Export → WAV file, then tick “Split mixer tracks”. Every mixer track becomes one stem.
  • Ableton Live: File → Export Audio/Video → Rendered Track: “All Individual Tracks”, start at 1.1.1.
  • Any other DAW: export each track or group from the very start of the project, so all files start at the same point.
  • Groups are enough (Kick, Bass, Drums, Music, FX). Name files clearly: the category comes from the file name (kick, bass, hats, pad, lead, vox, fx …), and you can fix it afterwards.
  • On iPad: in the file picker tap “Select” to pick several files at once.
